# Pantler website

The public pages for Pantler: The Pantry App.

- `index.html` — home
- `privacy.html` — privacy policy
- `support.html` — support, and how to delete an account (`support.html#delete`)

These files are published by GitHub Pages at
https://shanepcondon-tech.github.io/pantler-site/

They are copied from the `site/` folder of Pantler's private app
repository, where they are kept in step with the app. Edit them there
first, then copy them here.
